# GARDEN DEFENSE

GARDEN DEFENSE is a fast-paced 2D garden-themed arena shooter built in Unity. You play as a tiny sprout guardian armed with a plant cannon, defending the garden from waves of invading insects.

Enemies enter from the right side of the arena while the player moves freely and fires automatically. During each run, defeated enemies provide coins and experience, diamonds occasionally drift into the arena, and three-choice upgrades let the player build stronger weapon combinations. Coins and diamonds can also be spent on permanent upgrades between runs.

## Features

- Five plant-inspired weapon types: laser, cold slash, knockback, homing, and explosive shots
- Random three-choice upgrades during each run
- Permanent attack, health, fire-rate, movement-speed, and projectile upgrades
- Enemy health and spawn rate that increase over time
- Collectible coins and diamonds saved between sessions
- Custom garden-themed characters, enemies, projectiles, terrain, and interface

## Controls

- Move: `WASD` or arrow keys
- Fire: automatic
- Pause: `Esc`
- Menus and upgrades: mouse

## Built With

- Unity 6.3 LTS
- Universal Render Pipeline 2D
- Unity Input System
- Unity Tilemap
- TextMesh Pro
